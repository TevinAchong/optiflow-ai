# OptiFlow AI

A full-stack AI and optimization platform for industrial planning scenarios.

## Goal
This project simulates industrial inventory, detects constraint violations, optimizes operational schedules, forecasts future states, and explains recommendations through an AI copilot. 

## Main capabilities
- Synthetic industrial data generation
- Inventory simulation
- Constraint violation detection
- Optimization engine
- ML forecasting
- AI explanation layer
- Dashboard and report export

## Tech Stack
- Python + FastAPI
- C++ + CMake + pybind11
- PostgreSQL
- React + Next.js + Tailwind
- Docker
- Azure deployment later
